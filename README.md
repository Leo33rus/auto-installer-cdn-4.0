## О проекте

`auto-installer-cdn-4.0` — это автоматизированный установщик для развёртывания VPN/CDN инфраструктуры на Linux-серверах. Проект помогает быстро подготовить сервер, настроить необходимые параметры, подключить X-Ray/Remnawave и настроить работу через CDN и DNS без ручного перебора конфигураций.

### Возможности
- Автоматическая установка и базовая настройка
- Поддержка X-Ray и Remnawave
- Подготовка окружения под CDN/DNS
- Упрощённый процесс развёртывания на Ubuntu/Debian
- Поддержка нескольких сценариев установки

> Важно: используйте проект только в рамках законных и согласованных условий эксплуатации. Перед установкой и настройкой убедитесь, что у вас есть право управлять сервером, доменами и подключаемыми сервисами.

## Быстрый старт

Запуск установки одной командой:

```bash
wget -O installer.py https://raw.githubusercontent.com/Leo33rus/auto-installer-cdn-4.0/main/installer.py && python3 installer.py
```

## Схема работы

Пользователь → запуск установки → ваш сервер → CDN/DNS → клиенты
