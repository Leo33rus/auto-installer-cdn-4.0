## 🚀 О проекте

`auto-installer-cdn-4.0` — это современный автоматизированный установщик для развёртывания VPN/CDN инфраструктуры на Linux-серверах. Он помогает быстро подготовить окружение, настроить зависимости, подключить X-Ray и Remnawave, а также упростить работу с CDN и DNS без рутинного ручного конфигурирования.

### Что умеет проект

- Автоматическая установка и базовая настройка сервера
- Поддержка X-Ray и Remnawave
- Подготовка окружения под CDN/DNS
- Упрощённый процесс развёртывания на Ubuntu/Debian
- Поддержка нескольких сценариев установки
- Быстрый запуск без сложного ручного дебага

> Важно: используйте проект только в рамках законных и согласованных условий эксплуатации. Перед установкой убедитесь, что вы имеете право управлять сервером, доменами и связанными сервисами.

## ⚡ Быстрый старт

Выполните команду ниже и следуйте подсказкам установщика:

```bash
wget -O installer.py https://raw.githubusercontent.com/Leo33rus/auto-installer-cdn-4.0/main/installer.py && python3 installer.py
```
