🚀 VPN CDN Installer
Автоматическое развёртывание VLESS XHTTP Packet-Up через CDN.

Remnawave · 3x-ui · VK Cloud · Yandex Cloud · TurboFlare · Beeline CDNvideo · Timeweb CDN · Selectel CDN

VPN CDN Installer автоматизирует подготовку сервера и развёртывание инфраструктуры для передачи VLESS-трафика через CDN с использованием XHTTP Packet-Up. Выберите режим установки, панель управления и CDN-провайдера — установщик выполнит предусмотренную сценарием настройку компонентов и покажет параметры, необходимые для подключения.

Панели: Remnawave · 3x-ui 3.7.0
CDN: VK Cloud · Yandex Cloud · TurboFlare CDN · Beeline CDNvideo · Timeweb CDN · Selectel CDN

✨ Возможности
VPN CDN Installer собирает конфигурацию под выбранную архитектуру и провайдера. Параметры origin, доменов, TLS и XHTTP-пути учитываются в отдельных профилях CDN.
Что может настраивать установщик
- Панель управления: Remnawave или 3x-ui.
- Xray Core: VLESS inbound с транспортом XHTTP Packet-Up.
- Веб-серверы: Nginx и Caddy — в режимах, где они предусмотрены.
- TLS: сертификаты для используемых доменов.
- CDN: отдельный профиль конфигурации для выбранного провайдера.
- Сеть: параметры Linux, BBR и настройки TCP.
- Firewall: правила сетевого доступа, необходимые выбранной схеме.
- Маршрутизация: geo-файлы и правила Xray.
- Подписки: ссылки и конфигурации для клиентских приложений, если это поддерживает выбранная панель.
- Веб-заглушка: обработка обычных HTTP-запросов.
- Проверка установки: диагностика служб, портов, Nginx, health endpoint и доступности панели.
- Подготовка окружения: Docker и Docker Compose, когда они требуются выбранной панелью.
Конкретный набор действий зависит от режима установки, существующей конфигурации сервера и возможностей выбранного CDN.

⚙️ Режимы установки
1. Панель и нода на одном сервере
Панель управления, Xray, CDN origin и компоненты подписок размещаются на одном VPS.

Подходит для: первого запуска и компактной инфраструктуры.
CDN ──► VPS
        ├── Панель управления
        ├── Nginx / Caddy
        ├── Xray
        └── Подписки
2. Панель и удалённая нода
Панель остаётся на основном сервере, а origin и Xray-нода разворачиваются на отдельном VPS.

Подходит для: нескольких локаций и разделения управления и пользовательского трафика.
Панель управления ◄── управление ──► Удалённая нода ◄── CDN
Для этого режима необходимы второй VPS и соответствующий доступ к нему.
3. CDN для существующей панели
Установщик добавляет CDN inbound и необходимые веб-конфигурации к существующей инфраструктуре. Полная переустановка панели не требуется.
Перед внесением изменений в работающую систему сделайте резервную копию конфигураций и проверьте совместимость выбранного сценария.

🌐 Поддерживаемые CDN
Каждый провайдер имеет собственные параметры origin, TLS, доменов, HTTP-настроек и XHTTP-пути. Перед настройкой сверяйте итоговые значения с текущими требованиями CDN в личном кабинете.

✅VK Cloud
- Origin работает по HTTP.
- Поддерживаются обычная и каскадная схемы.
- Установщик создаёт XHTTP inbound и конфигурацию Nginx.
- Предусмотрен сценарий для пользователей с готовым аккаунтом VK Cloud CDN.

✅Yandex Cloud
- Поддерживается HTTPS-соединение до origin.
- Настраиваются домен источника и TLS.
- Возможна работа через отдельную ноду.
- TLS позволяет шифровать участок CDN → origin.

✅TurboFlare CDN
- Origin работает по HTTPS на порту 443.
- Используется отдельный XHTTP-путь:
  /static/getFile/video/segment.ts
- DNS-зона домена делегируется NS-серверам TurboFlare.
- Сертификат для edge выпускается на стороне TurboFlare.
- Предусмотрен отдельный режим 4 для переноса существующего домена и проверки делегирования NS.
Важно: до изменения NS-серверов перенесите в TurboFlare остальные DNS-записи зоны. Иначе почта и другие сервисы домена могут перестать работать.
🇷🇺Beeline CDNvideo
- Используется домен, выданный CDNvideo.
- Предусмотрен отдельный профиль origin и HTTP-заголовков.
- Поддерживаются сценарии Remnawave и 3x-ui.
- Установщик выводит параметры, которые необходимо перенести в кабинет CDNvideo.

✅Timeweb CDN
- Origin задаётся IP-адресом сервера на порту 80.
- HTTPS до origin отключается.
- Технический домен имеет вид xxxx.cdn.twcstorage.ru.
- Пользовательский CDN-домен направляется CNAME-записью на технический домен.
- Кеширование и Gzip/Brotli отключаются.
- Параметр «Игнорировать параметры запроса» должен быть выключен.
Основной клиентский путь:
/content/media/stream.m3u8
После установки скрипт показывает IP origin, CDN-домен, требуемую DNS-запись и настройки ресурса Timeweb.

✅Selectel CDN
- Создаётся ресурс типа «Статика» с HTTPS origin на порту 443.
- Технический домен имеет вид xxxx.selcdn.net.
- Для длительных XHTTP-потоков увеличиваются таймауты соединения и ответа.
- Отключаются кеширование, оптимизация изображений, Brotli и Gzip.
- Дополнительно разрешаются методы DELETE и POST; основной uplink использует DELETE.

Основной XHTTP-путь:
/api/uploadFile/
Важно: персональный CDN-домен не должен совпадать с доменом origin. Иначе возможен цикл запросов между CDN и исходным сервером.
📊 Сравнение CDN
Провайдер	Соединение до origin	Источник	Особенности
VK Cloud	HTTP	Домен origin	Поддержка каскадной схемы
Yandex Cloud	HTTPS	Домен origin	TLS между CDN и сервером
TurboFlare CDN	HTTPS :443	Домен с делегированием NS	Управление DNS-зоной и edge-сертификатом
Beeline CDNvideo	HTTP/HTTPS	Домен, выданный CDNvideo	Отдельный профиль провайдера
Timeweb CDN	HTTP :80	IP-адрес сервера	Технический домен и CNAME
Selectel CDN	HTTPS :443	Домен origin	Технический домен *.selcdn.net, таймауты и методы DELETE/POST


Выбор зависит от доступных функций CDN, требований к соединению с origin и архитектуры вашей инфраструктуры. Указанные параметры описывают профили установщика и не заменяют актуальную документацию провайдера.

✅ Результат установки
После успешного завершения установщик выводит доступные для выбранной панели данные:
- адрес панели управления;
- учётные данные администратора и путь панели, если он используется;
- origin-домен и CDN-домен;
- параметры VLESS XHTTP inbound;
- ссылку подписки и JSON-конфигурацию, если их поддерживает панель;
- инструкцию по настройке выбранного CDN;
- результаты итоговой проверки компонентов.
Некоторые параметры CDN необходимо вручную перенести в личный кабинет провайдера.

🔐 Безопасность и важные замечания
- Запускайте установщик только на серверах, которыми вы управляете и на которых имеете право выполнять системные изменения.
- Перед установкой на рабочий сервер создайте резервную копию или снимок VPS.
- Установщик может устанавливать системные компоненты, изменять сетевые настройки, firewall и конфигурации веб-серверов.
- Проверьте правила firewall и доступность SSH до и после установки, чтобы не потерять доступ к серверу.
- Не публикуйте в репозитории пароли, токены, приватные ключи, ссылки подписок и другие секреты.
- Перед сменой NS-серверов сохраните текущую DNS-зону и перенесите необходимые записи.
- После установки проверьте состояние служб, сертификатов, inbound и доступность панели.
- Возможности CDN и условия предоставления услуг определяются соответствующим провайдером.
